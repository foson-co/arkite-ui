## Quick start

Components need React, Tailwind CSS v4, and a few peer packages — `init` installs the peers and writes the theme CSS in one shot (manual steps: [Getting Started](?path=/docs/getting-started--docs)):

```bash
npx @arkite-ui/core init
```

```tsx
import { Button, LocaleProvider, zhTW } from '@arkite-ui/core'
import '@arkite-ui/core/styles.css'

<LocaleProvider locale={zhTW}>
  <Button variant="primary">開始使用</Button>
</LocaleProvider>
```
